# E.F.F.E.C.T. Fitness — Premium Website Redesign Concept

> Atlanta's Premier Physical Performing Arts Gym • Where Health, Hustle, and Heart Collide.
> **"Let's Get Paid!"**

A high-converting, athletic, modern digital experience designed for **E.F.F.E.C.T. Fitness** (1995B Metropolitan Pkwy SW, Atlanta, GA).

---

## ⚡ Tech Stack

- **Framework**: React 19 + TypeScript + Vite
- **Styling**: Tailwind CSS v4
- **Icons**: Lucide Icons & Custom SVG Brand Icons
- **Animation & FX**: Web Audio API Drumline Synthesizer, Canvas Confetti

---

## 🚀 Key Features

- **Cinematic Hero**: Full-screen athletic visuals, editorial typography, and quick stats.
- **Brand Story & Formula**: Acronym breakdown (Effective • Focused • Fast • Exceptional • Creative • Training) & cultural pillars.
- **Class Matrix**: Interactive cards with intensity flame meters, calorie burn rates, and modal details.
- **Weekly Schedule & Spot Booking**: Interactive day filter, spot counter, and reservation modal.
- **Personal Training & Matchmaker**: Mini-quiz matching athletes with coaches.
- **Editorial Coach Roster**: Founder Dooley, Reggie Ball, Coach Cali, Coach Daja, and staff profiles.
- **Community & Culture**: Spreading the Health Juice Bar, All-Star Saturday Market, and Cause of E.F.F.E.C.T.
- **Transformation Stories**: Real member milestone metrics and quotes.
- **On-Demand & App**: Livestream schedule, workout archive, and store download links.
- **Transparent Memberships**: Autopay vs. Monthly switcher, $0 Free First Class Pass, and side-by-side comparison table.
- **Facility & Location**: Interactive Google Maps embed, operating hours, and amenities.
- **Search & Audio**: Command Palette (`Ctrl+K`) and HBCU drumline rhythm synthesizer.

---

## 🛠️ Getting Started

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
